# JKSPDC Website Project

## Project Overview

This repository contains the development of the official website for the Jammu & Kashmir State Power Development Corporation (JKSPDC).

The objective is to build a modern, secure, fast, accessible, and maintainable government website that complies with GIGW 3.0 guidelines and follows industry best practices while remaining easy to manage for many years.

---

# Objectives

- Build a professional PSU/Government website.
- Fully comply with GIGW 3.0 wherever applicable.
- Ensure WCAG 2.2 AA accessibility.
- Deliver excellent performance on desktop and mobile.
- Follow secure development practices based on OWASP.
- Maintain clean, modular, and scalable architecture.
- Keep the website simple to maintain and extend.

# Project Principles

Every decision made in this project should prioritize:

1. Accessibility
2. Security
3. Performance
4. Maintainability
5. Simplicity
6. Scalability
7. Government Compliance

---

# Development Philosophy

This project values long-term stability over rapidly changing trends.

Code should always be:

- Readable
- Reusable
- Modular
- Well documented
- Type-safe
- Easy to maintain

Avoid unnecessary complexity and over-engineering.

---

# Government Website Standards

The website should:

- Follow GIGW 3.0 recommendations.
- Meet accessibility requirements.
- Support keyboard navigation.
- Work across modern browsers.
- Be mobile responsive.
- Use semantic HTML.
- Respect privacy and security standards.
